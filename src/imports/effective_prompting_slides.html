Topic 1
The four pillars of effective prompting
Think of it like giving directions — you wouldn't just say "go to the store." You'd specify which store, give the address, explain why, and adjust if needed.
Pillar 1
Be specific
State exactly what you want — content, tone, audience, purpose, word count.
Pillar 2
Technical details
Include specs, formats, constraints, and parameters that affect output quality.
Pillar 3
Give context
Explain the background, purpose, and audience so the AI can tailor the response.
Pillar 4
Iterate
Refine and improve through dialogue — don't expect perfection on the first try.
Topic 1 — Examples
Specific vs. vague
See how adding details transforms a vague request into one the AI can actually answer well.
Pillar 1: be specific
VAGUE
"Write about customer service"
SPECIFIC
"Write a 300-word guide on handling angry customers in retail, including 3 de-escalation techniques and appropriate phrases to use"
VAGUE
"Help me with my presentation"
SPECIFIC
"Create an outline for a 15-minute presentation on Q4 sales results for executive leadership, highlighting 3 key achievements and 2 areas for improvement"
Pillar 3: give context
NO CONTEXT
"Draft an email declining a meeting"
WITH CONTEXT
"Draft an email declining a vendor meeting — we've already chosen a different supplier, but want to keep the door open for future work"
Topic 2
Controlling length and format
Specifying format ensures output is immediately usable — paste-ready tables, scannable bullets, or executable code.
Format 1
Bullet points
Best for quick scanning, presentations, summaries
Format 2
Tables
Best for comparisons, pros/cons, feature lists
Format 3
Step-by-step
Best for processes, tutorials, instructions
Format 4
Numbered explanations
Best for prioritized lists, sequential concepts
Format 5
Pseudocode / flowchart
Best for decision trees, logic flows, algorithms
Example — table format
PROMPT
"Compare Asana, Trello, and Monday.com in a table with columns for Pricing, Best For, Key Features, and Learning Curve."
Topic 3
Break tasks into smaller steps
Large, complex requests often produce generic or error-prone output. Smaller steps give you control, clarity, and quality at each stage.
Wrong — all at once
ONE GIANT PROMPT
"Create a complete contact form with validation, database storage, email notifications, spam protection, responsive design, and CRM integration."
Result: overwhelming, errors compound, hard to debug, you don't understand how it works.
Right — broken down
1
HTML structure
Basic form fields with semantic HTML5
2
Styling
Responsive CSS matching brand colors
3
Validation
JS checks on each field with error messages
4
Backend email
PHP script with security checks
5
Spam protection
Google reCAPTCHA v3
Topic 3 — why it matters
Five reasons to decompose tasks
Breaking things down isn't just about managing complexity — it's about staying in control of the process.
1
Manageability — smaller tasks are easier to understand, execute, and verify before moving on.
2
Progressive learning — you understand each piece before building on top of it.
3
Issue isolation — when something goes wrong, you know exactly which step caused it.
4
Quality control — review and approve each piece before proceeding to the next.
5
Flexibility — change direction mid-process based on what each step reveals.
Topic 4
Iterate — treat it as a conversation
Don't expect perfection on the first try. The prompt → evaluate → revise loop mirrors how humans naturally communicate.
1
Prompt
Start with a clear but not necessarily perfect request
2
Evaluate
Review the output against your actual needs
3
Revise
Provide feedback — adjust tone, length, structure, examples
Common refinement types
Adjust tone
More casual, more formal, friendlier
Change length
Shorter summary or longer detail
Add info
Fill in missing sections or examples
Restructure
Reorder, reprioritize, reformat
Topic 4 — example
Iteration in action: job description
Watch how three rounds of feedback transform a generic draft into a compelling, accurate job post.
Initial prompt
"Create a job description for a Marketing Manager."
↓
Iteration 1 — add specificity
"This is too generic. We're a B2B SaaS startup. Add requirements for digital marketing, content strategy, and marketing automation tools."
↓
Iteration 2 — adjust tone
"Make the tone more appealing to millennial professionals. Emphasize startup culture, flexibility, and growth. Remove corporate language."
↓
Iteration 3 — final details
"Add benefits: unlimited PTO, remote-first, $2k learning budget, equity. Reduce required experience from 7 to 5 years."
↓
Final output
Complete, compelling, accurate job description ✓
Topic 5
Prompt engineering inception
Use AI to help you build better prompts. Instead of crafting the perfect prompt yourself, let the AI interview you first — then generate an optimized prompt from your answers.
Stage 1 — the meta-prompt
What to say
"I'm going to give you a prompt. Ask me clarifying questions, then suggest a more effective version that will yield more detailed, accurate output."
The AI will ask about your goals, audience, format preferences, technical requirements, and constraints.
Stage 2 — use the optimized prompt
What you get
A precise, detailed prompt tailored to your actual needs — often better than what you'd write yourself.
The AI identifies gaps you hadn't considered. It teaches you what good prompts look like as you go.
When to use this technique
Unclear needs
When you're not sure exactly what you want
Complex topics
When there are many possible directions
New domains
When you're learning something unfamiliar
High stakes
When quality really matters the first time
Topic 5 — example
What the AI asks you
Starting prompt: "Give me example code for a React accordion menu." — here's what the AI would clarify before writing a single line.
1
Component type — functional with hooks, or class component?
2
Behavior — allow multiple sections open, or only one at a time? Animations?
3
Accessibility — ARIA labels, keyboard navigation needed?
4
Data structure — array of objects? Will content include HTML or just text?
5
Styling — plain CSS, CSS Modules, Tailwind? Include basic styles or structure only?
6
TypeScript — should the output include full type definitions?
Summary
Key takeaways
Five habits that will immediately improve every prompt you write.
1
Be specific. Include content type, tone, audience, word count, and purpose in every prompt.
2
Specify the format. Tell the AI whether you want bullets, a table, step-by-step, or code.
3
Break it down. One requirement at a time — review before moving to the next step.
4
Iterate. The first output is a draft. Refine tone, length, and structure through follow-up messages.
5
Use the meta-prompt. Ask AI to interview you and craft a better prompt before diving into the actual task.
